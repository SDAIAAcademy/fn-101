# The fix, in my own words

The report groups the anomalies by district in a dictionary that should hold one list per district. The dictionary was built by a method that takes one starting value and hands that same value to every key, and the starting value was a single empty list. So the six districts did not have six lists; they had six names for one list. Each anomaly was added to "its" district's list, which was everybody's list, and in the end every district showed all eighteen. It is the aliasing of the first day, hidden inside a dictionary. The repair builds the dictionary so that a new empty list is made for each district separately; after that, adding to one district's list cannot be seen from any other. The total was always right, because the anomalies themselves were found correctly; only their grouping was shared.
