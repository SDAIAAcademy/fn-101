# Entry quiz

Ten questions, fifteen minutes, without running anything and without an assistant. Eight right
answers mean you are ready for Day 1. With fewer, do the sheet of the questions you missed again,
and tell your trainer before the course starts: nobody is turned away for the result.

**1.** What does `print(7 // 2, 7 % 2)` print?

- A. 3.5 1
- B. 3 1
- C. 3 0.5
- D. 4 1

**2.** After `a = 5` and `a = a + 1`, what is `a`?

- A. 5
- B. an error: a is already 5
- C. 6
- D. a + 1

**3.** What is `"12" + "3"`?

- A. 15
- B. an error
- C. "123"
- D. "15"

**4.** Which line compares two values?

- A. x = 3
- B. x == 3
- C. x := 3
- D. x => 3

**5.** How many times does the body of `for i in range(4):` run?

- A. 4
- B. 3
- C. 5
- D. it depends on i

**6.** `values = [10, 20, 30]`. What is `values[1]`?

- A. 30
- B. 10
- C. an error
- D. 20

**7.** Which condition is true for `m3 = 200`?

- A. m3 > 200
- B. m3 < 200
- C. m3 >= 200
- D. m3 != 200

**8.** What does `float("N/A")` do?

- A. gives 0.0
- B. gives None
- C. gives "N/A"
- D. raises an error

**9.** In `if a:` followed by an indented line and then a line that is not indented, when does the last line run?

- A. only if a is true
- B. only if a is false
- C. always
- D. never

**10.** `total = 0`, then a loop adds 2 three times, then `print(total)` after the loop. What is printed?

- A. 6
- B. 2
- C. 2 4 6
- D. 0
